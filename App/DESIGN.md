# 循环计时 · 视觉方向

本设计参考用户提供的扁平插画与暖色计时界面。休息页和完成页的人物素材按用户提供的插画制作配色变体。

## 已采用的设计规则

| 元素 | 当前方案 |
| --- | --- |
| 主视觉 | 首页使用留白与卡片；计时段显示逆时针圆形倒计时；休息与完成页使用无背景框的人物插画，衣纹改为湖绿色 |
| 基础背景 | 暖米白 `#FEFBF6`，配纯白卡片和深橄榄文字 `#303D2E` |
| 主色 | 草绿 `#7A9E5E`，用于主按钮与进度；深绿 `#577843` 用于文字与导航强调 |
| 辅助色 | 青绿 `#14A89C`、浅蓝 `#219EBF` 用于不同计时方式；蜂蜜黄 `#CFA35C` 用于间隔 |
| 卡片 | 大圆角、暖米色细边 `#E6D9C4`、浅阴影与充足留白 |
| 字体 | iOS 系统字体；大号倒计时采用圆润粗体并固定数字宽度 |
| 动效用途 | 计时完成时小星星从屏幕中心向随机方向四溅，距离、大小与飞行速度各不相同，再按不同时间缓缓淡出；采用湖绿、草绿、蓝、紫、黄、珊瑚色，不遮挡结果操作 |

## 页面映射

- **首页**：页面大标题使用 34 点圆角粗体，并作为记录页、设置页的标题位置与字号基准。标题下方并排展示“单步骤重复”和“多步骤循环”；接着是运行中入口与个人项目列表。运行中入口可左滑移除本次计时。“我的项目”仅展示用户保存的项目名称，空列表不放示例项目。
- **新建页**：项目名称卡片、空白步骤区、添加步骤、整套循环与总时长依次排列。添加步骤直接生成可编辑的计时卡片；名称在卡片首行编辑，时长按小时、分钟、秒滚动，计时步骤始终显示可直接输入的重复次数。整套循环也直接输入次数；总时长仅保留单行合计。保存后才进入“我的项目”。
- **一次性设置页**：首页两种计时方式分别进入单步骤或多步骤设置；小时、分钟、秒的数字各自滚动，单位固定在选中行，不使用整行底色。每次打开时长均从 0 秒开始；重复次数为直接输入。多步骤页与项目步骤卡片共用计时/间隔切换、逐步重复及重复间休息设置，整套循环可另设间隔。预计总时长只显示合计值。
- **计时页**：先准备倒数 3 秒，再显示圆形倒计时时钟；指针与进度环同向逆时针移动，右上角可切换数字视图。休息段使用湖绿色背景与同色衣纹人物，不在插画内重复写“休息”。只有保存的项目在顶部正中显示较大的项目名。
- **结果页**：完成时显示湖绿色庆祝人物和“任务达成！”，全屏星星动画后展示计时统计与再来一次入口。提前结束并保存进度时沿用相同的暖米白背景、白色统计卡片和排版，显示无背景框的思考人物，衣纹和“再来一次”按钮为湖蓝色，保留“本次已结束”及进度统计。
- **记录页**：以“历史记录”为唯一页面标题，汇总完整完成的项目次数与有效计时，下方直接列出记录，不加入训练或考试专用字段。
- **设置页**：“震动提醒”控制 App 打开时的阶段切换轻振与完成反馈，不改变手机的振动模式。
