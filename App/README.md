# 循环计时 · iOS 首版工程

本工程依据 [PRD v0.3](../循环计时_PRD_v0.3.md) 搭建，最低 iOS 版本为 17。界面使用 SwiftUI；项目、练习记录和运行状态保存在本机，无账户或服务器依赖。

[静态设计预览](./DesignPreview.png)展示首页与计时页的视觉方向，供讨论使用；它不是模拟器截图。
[视觉规则](./DESIGN.md)记录了如何把用户的参考图转为本产品的界面。

## 当前实现

- 创建、编辑、复制、归档、恢复计时项目。
- 首页两种计时方式可直接进入一次性设置；结束后保留记录，但不加入“我的项目”。
- 单步骤重复、不同步骤顺序组合、循环组重复和整套重复。
- 计时段、显式间隔、步骤重复间隔、组间隔、整套间隔。
- 项目详情中的流程预览及配置限制：8 组、24 个配置步骤、48 个执行段、总时长 24 小时。
- 开始前 3 秒准备倒数、圆形时钟与数字倒计时切换、暂停、继续、提前结束；休息时显示人物打坐插画。首页的进行中卡片可左划移除，不保留未完成记录。
- 完成时播放内置提示音并显示多色星星从中心炸开至全屏的动画；可在设置中关闭声音。
- 本地通知安排阶段切换；暂停或结束时撤销旧通知。
- 本地记录、项目详情与汇总；异常恢复时保留已确认进度。
- 暖米白与草绿卡片界面、原生绘制时钟与应用图标。

自定义音效、奖励、步骤跳过、云同步属于后续版本。

## 在 Xcode 中运行

1. 安装与当前 macOS 兼容的完整 Xcode，打开 [CycleTimer.xcodeproj](./CycleTimer.xcodeproj)。工程的最低部署版本为 iOS 17。
2. 选择 `CycleTimer` scheme 与 iPhone 模拟器，运行。真机运行时，在 Signing & Capabilities 选择自己的 Apple 开发团队，并把 `com.example.cycletimer` 改成唯一的 Bundle Identifier。
3. 首次开始计时时允许通知。拒绝通知后，前台仍可计时，但锁屏提醒会受限。
4. 测试后台提醒请使用真机；模拟器不能替代锁屏、静音、专注模式和蓝牙耳机验收。

`Package.swift` 仅用于独立测试计时内核。安装匹配的 Swift / Xcode 工具链后，可在本目录运行 `swift test`。iOS App target 直接编译同一套核心源文件。

## 推荐手动验收

1. 创建 45 秒计时、15 秒间隔、重复 8 次的项目：预览总时长应为 7 分 45 秒，最后不追加自动间隔。
2. 创建 20、30、40、10 分钟四段：总时长应为 100 分钟。
3. 先让 A、B 各重复 3 次，再改成组循环 3 次，确认预览分别呈现 `AAABBB` 与 `ABABAB`。
4. 验证暂停、继续、提前结束、返回首页后再进入、强制关闭后恢复、权限被拒绝时的提示。
5. 在真机上按 PRD 第 12.1 节测试 48 段容量及锁屏通知延迟。

## 当前环境的验证范围

已在 Xcode 16.2 的 iPhone 16 Pro（iOS 18.3.1）模拟器上编译，并渲染首页、新建页和一次性多步骤设置页。锁屏提醒延迟、静音模式、蓝牙耳机与实际完成音量仍需在真机验收。
